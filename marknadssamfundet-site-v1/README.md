# Marknadssamfundet

Första versionen av Marknadssamfundets webbplats.

## Filer
- `index.html` – startsida
- `arkiv.html` – sökbart arkiv
- `artikel.html` – exempel på artikel/rapport
- `om.html` – om organisationen
- `butik.html` – butikssida
- `styles.css` – design
- `script.js` – meny och arkivsökning
- `assets/` – logotyper

Webbplatsen är byggd som en statisk sida och kan publiceras kostnadsfritt med GitHub Pages.
